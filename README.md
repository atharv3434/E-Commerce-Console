# E-Commerce-Console

🚀 Project: E-Commerce Console Application (Java-Only)
📌 Description
This is a Java-based console application that simulates a simple E-Commerce system, where users can:
✔ View available products
✔ Add products to cart
✔ Remove products from cart
✔ View the cart
✔ Proceed to checkout

The system follows Object-Oriented Programming (OOP) principles and uses ArrayLists to manage products and cart items.

✅ Features
✔ Product Listing – Displays a list of available products.
✔ Shopping Cart – Users can add or remove products.
✔ Order Checkout – Finalize and pay for the items.
✔ User-Friendly Console Interface – Simple to navigate.
